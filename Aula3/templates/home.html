O que é o Flask?

O Flask é um micro-framework escrito em Python com o objetivo de facilitar a criação de aplicações web e APIs. Ele é categorizado como um "micro-framework" porque não exige ferramentas ou bibliotecas específicas, mantendo o núcleo simples, mas altamente expansível através de extensões comunitárias.

Principais Vantagens

  • Simplicidade: Código limpo, fácil de entender e ideal para iniciantes.
  • Flexibilidade: Permite escolher qual banco de dados e ferramentas de validação utilizar.
  • Documentação Excelente: Uma comunidade ativa com guias e tutoriais completos.
  • Mecanismo de Templates: Utiliza o Jinja2 integrado para renderizar HTML dinâmico.

Como Instalar

A instalação é extremamente simples e feita diretamente através do terminal utilizando o gerenciador de pacotes do Python (pip):

pip install flask

Uma Aplicação Mínima

Veja como é fácil criar uma rota e rodar um servidor local básico com Flask:

from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "<h1>Olá, Mundo! Este é o Flask funcionando.</h1>"

if __name__ == "__main__":
    app.run(debug=True)

Salve o código acima como app.py e execute-o com o comando python app.py no terminal. Abra o navegador no endereço indicado para visualizar a mensagem.
